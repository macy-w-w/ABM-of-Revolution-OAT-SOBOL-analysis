# ABM-of-Revolution-OAT-SOBOL-analysis
Project creating an Agent Based Model to model a violent revolution, then running SOBOL analysis to see most impactful variables in success/failure
ABM was based off an already existing model discussed in the following paper: https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0154175
Model (ABM) was created in NetLogo Ver 7.0.1. I manually rewrote the model to work in an updated NetLogo version in order to use Python for analysis.
All analysis was done in Python using the pyNetLogo library.
To run, Java must be in version 21 due to issues in pyNetLogo.
